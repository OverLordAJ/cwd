Usability Test Report

Website Tested: University Course Registration Portal

Task Analysis

Task 1: Locate the Fall Course Catalog

Time to complete: 01 minute, 45 seconds

Description: The user was asked to find the upcoming Fall semester course catalog from the homepage. They initially struggled because the link was nested under a vaguely named "Academic Resources" dropdown rather than having a dedicated button. They clicked around the "Student Life" tab before using the site's search bar to finally locate the catalog.

Task 2: Filter Courses by Computer Science Department

Time to complete: 00 minutes, 55 seconds

Description: The user needed to filter the massive list of classes to only show Computer Science courses. They found the filter sidebar relatively quickly, but there was slight friction because the department was listed under "Math & Computer Science" rather than "Computer Science" on its own. It required a bit of scrolling to find the right checkbox.

Task 3: Add a 400-Level Class to the Schedule Planner

Time to complete: 02 minutes, 10 seconds

Description: The user attempted to add a specific 400-level course to their mock schedule. The primary struggle here was the lack of visual feedback. After clicking "Add to Planner," there was no pop-up or notification confirming the action. The user clicked it three times, resulting in multiple duplicate errors, before realizing they had to manually navigate to a separate "My Planner" page to verify it worked.

Task 4: Identify Course Prerequisites

Time to complete: 01 minute, 15 seconds

Description: The user was asked to find the prerequisites for the class they just added. They correctly clicked the course title expecting a detailed modal window to appear. However, the prerequisites were buried at the very bottom of a long block of text. The text was unformatted and hard to scan, causing the user to read through the entire course description before finding the prerequisite requirements.

Task 5: Locate the Add/Drop Deadline

Time to complete: 03 minutes, 30 seconds

Description: This was the most difficult task. The user needed to find the final date to drop a class without penalty. They looked in the course description, the planner interface, and the sidebar menu. They eventually had to leave the registration portal entirely and go back to the university's main academic calendar page to find the date. The lack of contextual links within the registration portal was a major friction point.
